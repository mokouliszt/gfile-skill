# gfile

[English](README.md) | **日本語**

Claude(claude.ai の Web / モバイル)がサンドボックスから
[ギガファイル便 (gigafile.nu)](https://gigafile.nu/) でファイルを共有できるようにする Agent Skill です。

claude.ai からユーザーに渡せるファイルは **1ファイル30MBまで** です。APK・動画・データセットなどそれを超える成果物は、チャット上にファイルカードが出ても実際にはダウンロードできません。このskillを入れると、Claudeはそうしたファイルをギガファイル便にアップロードし、共有URL・保存期限・ダウンロードキー・削除キーを返します。

## 特長

- **2つのトリガー**: ユーザーがギガファイル便での共有を明示的に指示したとき、または Claude 自身の成果物が30MBのダウンロード上限を超えたとき。
- **ダウンロードキー必須。** 保存期限とダウンロードキーは、Claude が選択式の質問UIで毎回確認します。キーの既定の候補は今日の日付 `MMdd`(10月5日なら `1005`)で、任意のキー(半角英数1〜4文字)も入力できます。キーの設定と確認のどちらかに失敗した場合、アップロードしたファイルは自動で削除されます。
- **機密情報は絶対にアップロードしない。** 内蔵スキャナ(`secret_guard.py`)がアップロード前に全ファイルを検査します。zip / apk / jar / tar / gz の中身も再帰的に調べ、APIキー・トークン・秘密鍵・パスワード・`.env`・`auth.json`・keystore などを見つけると拒否します。検査を無効にする手段は**意図的に用意していません**。中身を確認できないアーカイブ(パスワード付きzip・7z・rar)も拒否します。
- **共有前に個人情報を検査。** 対象は氏名・住所・電話番号・メールアドレス・生年月日・口座番号やカード番号・マイナンバー・GPS位置情報・ファイルの作成者情報です。次の4つの方法を組み合わせて検出します。
  - [OpenAI Privacy Filter](https://huggingface.co/openai/privacy-filter)(onnxruntimeでローカル実行)
  - 日本語・英語向けの正規表現
  - 画像メタデータ
  - スクリーンショット等のOCR(Tesseract jpn+eng)

  さらに Claude 自身が画像を目で見て、顔・画面上の氏名・身分証などを確認します。自動でのマスキングや削除は行わず、検出結果を場所付きで**すべて**提示して、どうするかを確認します。コードの識別子・企業名・サンプルデータなど明らかな誤検出は無視します。
- **報告漏れなし**: 共有URL・保存期限(日数と期限日)・ダウンロードキー・削除キーを必ずすべて報告します。
- 公式Webアップローダと同じく100MB単位で1つずつ順に送信します。複数ファイルやフォルダは自動でzipにまとめます。アップロードしたファイルのSHA-256表示と、削除キーによる削除にも対応しています。

## 動作要件

- **コード実行とファイル作成** を有効にした Web 版またはモバイル版の Claude
- 次のドメインに接続できる **ネットワーク設定**(「すべてのドメイン」など)
  - `gigafile.nu`、`*.gigafile.nu`(アップロード先)
  - `huggingface.co`、`*.hf.co`(Privacy Filter モデル)
  - `github.com`、`raw.githubusercontent.com`(OCR用言語データ)
- Python 3 と `requests`・`numpy`・`Pillow`・`onnxruntime`、Tesseract(claude.ai のサンドボックスにはインストール済み。`tokenizers` は自動でインストール)
- モデル用に空きディスク約1GBとメモリ約3GB(q4 ONNX重み約0.9GBをサンドボックスのセッションごとに1回ダウンロードし、SHA-256で検証)

## インストール

1. skillフォルダをzipにします(アーカイブの最上位に `gfile` フォルダ自体が来るようにします)。
   ```bash
   cd skills && zip -r ../gfile.zip gfile
   ```
2. Claude の設定画面の Skills から `gfile.zip` をアップロードし、有効にします。

## 使い方

Claude に話しかけるだけです。

- 「`build/app-release.apk` をギガファイル便で共有して」
- 「APKをビルドして送って」— APKが30MBを超えていれば、Claude が自動でギガファイル便に切り替えます。
- 「さっきのギガファイル便のファイルを削除して」

Claude はまず機密情報と個人情報を検査し、見つかったものを提示します。続けて保存期限(3 / 5 / 7 / 14 / 30 / 60 / 100日)とダウンロードキーを確認してからアップロードし、次のように返します。

```
- 共有URL: https://NN.gigafile.nu/MMDD-xxxxxxxx
- 保存期限: 7日(2026-10-12 まで)
- ダウンロードキー: 1005
- 削除キー: ab12
```

共有相手にはURLとダウンロードキーだけを伝えてください。削除キーを知っている人は誰でもファイルを削除できます。

### CLI(サンドボックス内で Claude が使うもの)

```bash
python3 skills/gfile/scripts/gfile.py check  <パス...>                   # サイズ確認と機密情報スキャン(通信なし)
python3 skills/gfile/scripts/gfile.py pii    <パス...> --json-out pii.json [--md-out pii.md]
python3 skills/gfile/scripts/gfile.py upload <パス...> --lifetime 7 --dlkey 1005 --pii-report pii.json \
                                      [--pii-reviewed] [--name 名前] [--json-out ファイル]
python3 skills/gfile/scripts/gfile.py delete <URL> --delkey ab12
```

`upload` は、同じファイルに対する個人情報レポートがないと実行できません。レポートに次のいずれかが含まれる場合は `--pii-reviewed` が必要です。Claude は、ユーザーが検出結果を確認して判断した後にだけこのフラグを付けます。

- 検出結果
- 目視確認が必要な画像
- モデルを使えなかったという記録

終了コード:

| コード | 意味 |
|---|---|
| `0` | 成功 |
| `2` | 入力が不正(`pii` の場合は、確認が必要な検出結果あり) |
| `3` | 機密情報スキャンで拒否 |
| `4` | ネットワークエラー |
| `5` | ギガファイル便からの応答が想定外 |
| `6` | ダウンロードキーの設定または確認に失敗(アップロード済みのファイルは削除済み) |
| `7` | 削除に失敗 |
| `8` | 個人情報レポートがない・古い・未確認 |

## リポジトリ構成

```
.
├── LICENSE
├── README.md / README.ja.md
└── skills/
    └── gfile/                  # skill本体(インストールするのはこのフォルダのみ)
        ├── SKILL.md
        ├── scripts/
        │   ├── gfile.py        # check / pii / upload / delete
        │   ├── secret_guard.py # 機密情報スキャナ(安全側で止める設計、無効化手段なし)
        │   └── pii_scan.py     # 個人情報スキャナ(報告のみ・加工しない)
        └── references/
            └── protocol.md     # ギガファイル便の通信仕様メモ(保守用)
```

## 制限事項・注意

- **非公式です。** ギガファイル便には公開APIがないため、公式Webアップローダと同じ通信先を使っています。ギガファイル便の運営とは無関係で、サイトの仕様が変わると動かなくなる可能性があります。ギガファイル便の利用規約に従ってご利用ください。
- ダウンロードキーはアップロード完了後でないと設定できません。そのため、アップロード直後の数秒間はキーなしでもファイルにアクセスできます(URLはランダムで、まだ誰にも共有されていない状態です)。
- 30MBという基準は claude.ai ヘルプセンターの記載「The maximum file size is 30MB per file for both uploads and downloads」(2026年10月確認)に基づいています。上限が変わった場合は `gfile.py` 内の定数を変更してください。
- 個人情報の検出には限界があります。
  - Privacy Filter は主に英語で学習されているため、日本語にも対応しますが精度は落ちます。
  - OCRは誤読することがあります。
  - 目視確認するのは関連性の高い20枚までです。
  - モデルが読むのは1回あたり40,000トークンまでです(1コアで4〜5分程度)。それを超えた分は正規表現だけで検査します。
  - コンパイル済みバイナリ(dex・.so 等)は検査しません。
- 機密情報スキャナは既知のパターンとの照合で判定しています。迷うものは拒否する設計で、たとえば Google APIキーが埋め込まれたAPKも拒否されます。ただし、あらゆる機密情報を検出できる保証はないため、機密情報を含むと分かっているファイルの共有は依頼しないでください。
